System Overview

This platform represents a real-time monitoring and control interface designed for an EMI-resilient quadcopter operating in high-voltage substation environments. The system ensures reliable data acquisition, transmission, and visualization even under severe electromagnetic interference conditions.

The architecture integrates onboard sensing, wireless telemetry, and a centralized control dashboard to enhance operational safety, inspection accuracy, and mission efficiency.

Project Description

This project focuses on the design and conceptual implementation of an EMI-resilient quadcopter intended for inspection of high-voltage substations.

Due to strong electromagnetic interference, conventional drones face instability, sensor inaccuracies, and communication failure. This system proposes a robust architecture capable of reliable performance under such conditions.

The dashboard represents a centralized control room used for real-time monitoring of critical drone parameters including temperature, proximity, battery, and mission duration.
